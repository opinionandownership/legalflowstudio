# Legal Flow Studio – Flow of Title

A web page that drafts the **Flow of Title** for a property legal opinion from an uploaded queries sheet (.docx).

- Upload the queries sheet: the list of documents table, its highlights and red text are read automatically.
- The flow is generated at once in the firm's format: "The Flow of Title" title, Bookman Old Style, 1.5 line spacing, no indentation.
- Download gives a Word file: the original document, then The Flow of Title, then the Queries.
- Previous flows are kept in each visitor's own browser.

No sign-in is needed to use the page. Only the owner of this repository can change it.
